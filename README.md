# 消费者愿意把多少购买决策交给 AI 购物助手

伦敦国王学院（King's College London）MSc Digital Economy 学位论文的研究展示。

**在线浏览：** https://dingyue-xu.github.io/ai-shopping-assistant-research/

*Consumer Adoption Barriers to AI Shopping Assistants in Chinese E-Commerce*

## 研究问题

AI 购物助手正在从“推荐商品”走向“替用户下单”。这项研究回答两个问题：

1. 自主度每提高一档，消费者的采纳意愿如何变化？
2. 在电商平台内（淘宝内嵌 AI 助手）还是在通用 AI 助手（千问）里遇到它，是否影响采纳？

## 设计

- 3（委托程度：仅推荐 / 代备单待确认 / 预算内全自动）× 2（淘宝内嵌助手 / 千问通用助手）组间情景实验
- 两款产品同属阿里巴巴，公司身份被控制，入口效应与品牌效应可以分开
- 有效样本 N = 267，量表信度 α .876–.942，操纵检验通过率 86.1%

## 主要发现

| 发现 | 证据 |
|---|---|
| 自主度是决定性变量，采纳意愿线性下降（5.11 → 4.29 → 3.27） | F(2, 256) = 71.11, p < .001, η²ₚ = .357 |
| 影响经由感知风险传导，而不是信任 | 风险中介 −.270, 95% CI [−.384, −.175]；信任路径不显著 |
| 入口影响很小，通用助手做电商没有先天劣势 | 差距 0.23 / 7 分，p = .062 |
| 价格对采纳的影响大于品类 | 低价 4.75 vs 高价 2.95；快消 4.56 vs 耐用品 3.52 |

## 产品启示

- 降低风险的机制（额度上限、白名单、可撤销授权、下单前确认）比品牌背书更能提升采纳
- 自动化能力逐级开放，没有可以一次放开的“安全档位”
- 自动下单从低客单价、高复购品类冷启动
